# Dottie

Nix flake for my macOS (nix-darwin) and Linux (standalone Home Manager) machines, sharing one Home Manager setup for zsh, Neovim, git and CLI tools.

```
flake.nix                   # inputs, mkDarwin/mkLinux helpers, host list
hosts/
  darwin/common/            # shared macOS: Homebrew casks, fonts, Touch ID sudo, system defaults
  darwin/razumikhin/        # host "Razumikhin"
  linux/common/             # shared Linux (empty for now)
  linux/frank/              # host "Frank"
home/                       # Home Manager modules used by every host
  default.nix               # imports the modules below
  packages.nix              # CLI tools and language toolchains
  shell.nix                 # zsh, oh-my-zsh, starship, fzf, zoxide, aliases
  neovim.nix                # Neovim, with config/nvim linked to ~/.config/nvim
  git.nix                   # git
config/nvim/                # NvChad config, plain Lua, not generated by Nix
```

## Hosts

| Flake output | Platform | System |
|---|---|---|
| `darwinConfigurations.Razumikhin` | macOS, nix-darwin + Home Manager | `aarch64-darwin` |
| `homeConfigurations.Frank` | Linux, standalone Home Manager | `x86_64-linux` |

Both build for the user `vlad.cuciureanu` (set in `flake.nix`), with the home directory at `/Users/vlad.cuciureanu` or `/home/vlad.cuciureanu`.

## Requirements

- Nix with flakes enabled. On macOS this must be [Determinate Nix](https://determinate.systems/nix/), because the darwin config sets `nix.enable = false` and leaves the Nix daemon to it:

  ```sh
  curl --proto '=https' --tlsv1.2 -sSf -L https://install.determinate.systems/nix | sh -s -- install
  ```

- macOS: [Homebrew](https://brew.sh), which nix-darwin uses for casks but does not install.
- The repo cloned to `~/.dotfiles`. The shell sets `$DOTFILES` to that path, and the `dotfiles`/`dots` aliases `cd` there.

```sh
git clone git@github.com:VladCuciureanu/Dottie.git ~/.dotfiles
cd ~/.dotfiles
```

## Apply

macOS, first run (before `darwin-rebuild` exists):

```sh
sudo nix run nix-darwin/master#darwin-rebuild -- switch --flake ~/.dotfiles#Razumikhin
```

After that:

```sh
sudo darwin-rebuild switch --flake ~/.dotfiles#Razumikhin
```

Linux, first run (before `home-manager` exists):

```sh
nix run home-manager/master -- switch --flake ~/.dotfiles#Frank
```

After that:

```sh
home-manager switch --flake ~/.dotfiles#Frank
```

To update inputs, run `nix flake update` (or `nix flake update <input>`) and apply again.

Things to know:

- macOS: Homebrew runs with `cleanup = "zap"`, so any cask or formula not listed in `hosts/darwin/common/default.nix` or the host file is uninstalled on every switch.
- macOS: Home Manager moves files it would overwrite to `<name>.backup` instead of failing. The Linux config has no such setting, so remove conflicting files first.
- zsh sources `~/.zsh/secrets.zsh` if it exists; keep secrets there, not in the repo.

[TLDR.md](TLDR.md) has a table of day-to-day commands and where to make common changes.

## Adding a host

1. Create `hosts/darwin/<name>/default.nix` or `hosts/linux/<name>/default.nix`, with the directory name in lowercase (the flake lowercases the hostname to find it), and import `../common`. Copy `razumikhin` or `frank` as a starting point; on macOS, set `networking.hostName` and `system.primaryUser`.
2. Add an entry to the matching block in `flake.nix`:

   ```nix
   darwinConfigurations = {
     "Razumikhin" = mkDarwin { hostname = "Razumikhin"; };
     "MyMac" = mkDarwin { hostname = "MyMac"; };  # system defaults to aarch64-darwin
   };

   homeConfigurations = {
     "Frank" = mkLinux { hostname = "Frank"; };
     "MyBox" = mkLinux { hostname = "MyBox"; system = "aarch64-linux"; };  # default is x86_64-linux
   };
   ```

3. Apply with `.#MyMac` or `.#MyBox` as above.
